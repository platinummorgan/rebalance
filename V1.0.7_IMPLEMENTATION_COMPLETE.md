Comprehensive analytics tracking for the Pro conversion funnel:

**Tracked Events:**
1. **`pro_banner_view`** - User sees banner on dashboard
2. **`pro_banner_tap`** - User taps banner CTA
3. **`pro_banner_dismiss`** - User dismisses banner
4. **`pro_screen_view`** - User views Pro features screen
5. **`upgrade_button_tap`** - User taps "Upgrade to Pro" button (tracks location + plan type)
6. **`purchase_flow_start`** - Google Play billing sheet opens
7. **`purchase_complete`** - User completes purchase (includes price + currency)
8. **`purchase_failure`** - Purchase fails (includes error message)
9. **`retirement_calculator_view`** - User views Retirement Calculator (tracks Pro status)

**What You Can Track:**
- **Banner → Pro Screen Conversion**: How many users tap the banner vs see it
- **Pro Screen → Purchase Conversion**: How many users buy after viewing Pro screen
- **Feature Discovery**: Which Pro features users try to access
- **Purchase Funnel Drop-off**: Where users abandon the purchase flow

## What You Need To Do Now

### Step 1: Set Up Firebase (REQUIRED) ⚠️

Firebase won't work until you add the configuration file. Follow the **detailed guide** in:

📄 **`FIREBASE_SETUP.md`** ← Complete step-by-step instructions

**Quick Summary:**
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create project "Rebalance"
3. Add Android app (package name: `com.wealthdial.app`)
4. Download `google-services.json`
5. Place file at: `android/app/google-services.json`
6. Update `android/build.gradle` and `android/app/build.gradle` (see guide)

**⚠️ Without this, the app will still work but analytics won't track anything!**

## Troubleshooting

### Banner not showing:
- Check: Are you logged in as Pro user? (banner hidden for Pro)
- Check: Did you dismiss it before? (stored in settings)
- Fix: Uninstall/reinstall app to reset

### Analytics not working:
- Check: Console logs for `[Analytics]` messages
- Check: Firebase initialized? (`[Main] Firebase initialized successfully`)
- Check: `google-services.json` in `android/app/`?
- Fix: See FIREBASE_SETUP.md troubleshooting section

### Errors when building:
- Run: `flutter clean`
- Run: `flutter pub get`
- Check: `android/build.gradle` has Google Services plugin?
- Check: `android/app/build.gradle` has `apply plugin` at bottom?

### Events not in Firebase Console:
- Wait: Events take 24-48 hours to appear
- Use: DebugView for real-time testing (see FIREBASE_SETUP.md)
- Check: Console logs to verify events are firing
