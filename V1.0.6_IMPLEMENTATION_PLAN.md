#### 2. Retirement Calculator 🔥🔥🔥 **CRITICAL PRO FEATURE**
**Status**: Completely missing  
**Type**: PRO feature  
**Why critical**: Flagship Pro feature that's advertised  

**What it does**:
- Calculate retirement savings projections
- Monte Carlo simulation (run 1,000+ scenarios)
- Show probability of success
- Compare different contribution amounts
- Model worst-case scenarios
- Save/compare multiple scenarios

**User Input**:
- Current savings: $150,000
- Monthly contribution: $500
- Expected annual return: 7%
- Years until retirement: 30
- Retirement goal: $1,000,000
- Worst-year drawdown: -30%

**Output**:
```
Base Case ($500/mo, 7% return):
→ 68% chance to hit $1M in 30 years
→ Median outcome: $1,127,450
→ 10th percentile: $842,300
→ 90th percentile: $1,456,800

With $150 more/mo:
→ 86% chance to hit $1M in 30 years
→ Or hit goal 3.2 years earlier

Bad-year stress test (-30% drawdown Year 5):
→ Recover by year 9 with continued contributions
```

**User Flow**:
1. User taps "Retirement Calculator" from Pro screen
2. Enters current savings & monthly contribution
3. Sets expected return & years to retirement
4. Sets goal amount
5. Runs simulation
6. Views results with probability chart
7. Adjusts sliders to see "what-if" scenarios
8. Saves scenarios for comparison

**Technical Steps**:
- Create retirement calculator service with Monte Carlo logic
- Random return generator (normal distribution)
- Run 1,000 simulations
- Calculate statistics (median, 10th/90th percentile, probability)
- Create UI with sliders and charts
- Use fl_chart for probability distribution chart
- Save scenarios to local storage

**Files to Create**:
- `lib/services/retirement_calculator_service.dart`
- `lib/features/retirement/retirement_calculator_screen.dart`
- `lib/data/models/retirement_scenario.dart` (Hive model)

**Files to Modify**:
- `lib/routes.dart` (add retirement calculator route)
- `lib/features/pro/pro_screen.dart` (link to calculator)
- `lib/data/models.dart` (add RetirementScenario model)

**Estimated Time**: 5-7 days

#### 3. Historical Performance 🔥🔥 **HIGH-VALUE PRO FEATURE**
**Status**: Completely missing  
**Type**: PRO feature  
**Why important**: Differentiates Pro from free, high perceived value  

**What it does**:
- Chart net worth over time
- Calculate returns (YTD, 1Y, 3Y, 5Y, All Time)
- Compare to benchmarks (S&P 500, 60/40 portfolio)
- Show best/worst months
- Display account-level performance

**Output Example**:
```
Your Returns:
• Year-to-Date: +12.4%
• 1 Year: +18.7%
• 3 Years: +9.2% annualized
• All Time: +11.8% annualized

vs. S&P 500:
• YTD: +15.2% (you: +12.4%)
• 1Y: +21.3% (you: +18.7%)

Best Month: March 2024 (+8.2%)
Worst Month: October 2023 (-4.1%)
```

**User Flow**:
1. User taps "Historical Performance" from Pro screen
2. Views net worth chart over time
3. Sees returns calculated for different periods
4. Compares to benchmarks
5. Filters by account or time period
6. Exports chart as image

**Technical Steps**:
- Use existing snapshot system (already collecting data)
- Calculate returns between snapshots
- Fetch benchmark data (S&P 500) from API or hardcode annual returns
- Create line chart showing net worth over time
- Calculate annualized returns
- Add benchmark comparison
- Create UI with fl_chart

**Files to Create**:
- `lib/features/performance/historical_performance_screen.dart`
- `lib/services/performance_calculator_service.dart`

**Files to Modify**:
- `lib/routes.dart` (add performance route)
- `lib/features/pro/pro_screen.dart` (link to performance)
- `lib/data/snapshot_service.dart` (add performance calculation methods)

**Estimated Time**: 4-5 days
